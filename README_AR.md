# منصة الدروس التعليمية — تحديث Google Forms والألعاب HTML

## ما تم إصلاحه
- روابط Google Forms الكاملة `docs.google.com/forms/.../viewform` تُفتح داخل المنصة باستخدام `embedded=true`.
- روابط `forms.gle` تُحل عبر الخادم ثم تُفتح بوضع التضمين الرسمي.
- ملفات Google Drive للفيديو والصوت وPDF والصور تستمر عبر مسار البث داخل المنصة مع دعم Range.
- الألعاب التعليمية يمكن الآن إدخالها كنص HTML كامل (HTML + CSS + JavaScript) من لوحة المعلم.
- المعلم يستطيع تعديل الكود المحفوظ وإجراء معاينة مباشرة قبل الحفظ.
- عند عرض اللعبة للطالب يتم عرض الناتج داخل iframe مع sandbox ولا يُرسل حقل HTML إلى بيانات الطالب.
- زر/صلاحية التنزيل غير مفعّلة في iframe، مع منع بعض إجراءات النسخ والسحب من واجهة المنصة.

## مهم
يجب أن تكون ملفات Google Drive المطلوبة متاحة بصلاحية «أي شخص لديه الرابط — مشاهد». ولا يمكن لأي تطبيق ويب ضمان منع أدوات المطور أو تصوير الشاشة بنسبة 100%.

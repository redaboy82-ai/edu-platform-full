# تحديثات إدارة المحتوى

تمت إضافة نظام إدارة محتوى موسع مع الحفاظ على وظائف المنصة السابقة:

- التحكم في إتاحة الفيديو والصوت والألعاب والاختبارات والكتب/المذكرات لكل الطلاب أو لطلاب محددين.
- كارت مستقل للكتب والمذكرات في لوحة المعلم.
- رفع PDF والصور (PNG/JPG/WEBP) بنفس أسلوب الرفع الحالي مع شريط تقدم وإغلاق نافذة الحفظ فور بدء الرفع.
- تعديل بيانات الملفات، استبدال الملف نفسه، أو حذفه.
- عرض الملفات للطالب وولي الأمر وفق الصف وقاعدة الإتاحة المحددة من المعلم.
- التحقق من الصلاحيات على الخادم، وليس الواجهة فقط.
- استمرار حساب ولي الأمر الواحد المرتبط بعدة أبناء.

## تشغيل

```bash
npm install
npm start
```

للنشر على Render، يجب استخدام تخزين دائم (Persistent Disk أو خدمة تخزين ملفات خارجية) للمجلدات `data`, `videos`, `audios`, `games`, و`documents` حتى لا تضيع الملفات عند إعادة نشر الخدمة.


## التخزين الدائم على Render
يستخدم المشروع الآن مجلد `/var/data` تلقائيًا عند تشغيله على Render، مع كتابة قاعدة البيانات بطريقة ذرّية حتى لا تتحول قاعدة البيانات إلى ملف فارغ بعد إعادة التشغيل. ملف `render.yaml` يربط `/var/data` بقرص Persistent Disk.
**مهم:** يجب أن يكون الموقع الحالي في Render منشأ/محدّثًا باستخدام `render.yaml` نفسه، وأن يظهر القرص `edu-data` في إعدادات الخدمة. إذا كانت الخدمة الحالية لا تحتوي على القرص، فلن يستطيع الكود وحده حفظ البيانات بعد إعادة التشغيل.

## المواد المتعددة داخل الصف
يمكن للصف الواحد الآن أن يحتوي عدة مواد. عند إضافة الطالب تظهر قائمة مواد يمكن من خلالها السماح بمادة واحدة أو عدة مواد أو حجب جميع المواد. ويمكن ربط الفيديو/الصوت/اللعبة/الكتاب/الاختبار بمادة محددة، ويتم التحقق من الصلاحية على الخادم.

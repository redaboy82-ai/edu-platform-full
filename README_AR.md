# منصّة الدروس — النسخة الجاهزة

هذه نسخة كاملة تعمل بخادم Node.js بدون مكتبات خارجية.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد `edu-platform-full`.
3. شغّل:

```bash
node server.js
```

4. افتح:

`http://localhost:3000`

## حساب المعلم الافتراضي

بيانات الدخول الافتراضية للمعلم هي: اسم المستخدم `redaawad` وكلمة المرور `135790`. لا تعرض المنصة هذه البيانات على شاشة الدخول.

بعد الدخول يمكنك تغيير كلمة المرور من: **الإعدادات → تغيير كلمة مرور المعلم**.

يمكن تخصيص البيانات عند أول تشغيل عبر متغيرات البيئة:

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `PORT`
- `DATA_DIR` لمجلد قاعدة البيانات
- `GAMES_DIR` لمجلد ملفات الألعاب

## حساب الطالب

من حساب المعلم اختر **الطلاب → طالب جديد**. المنصة تنشئ تلقائيًا:

- اسم دخول الطالب
- كلمة مرور الطالب
- كود ولي الأمر
- كلمة مرور ولي الأمر

يمكن إعطاء الطالب بيانات حسابه وولي الأمر بيانات حساب ولي الأمر.

## الألعاب التعليمية

من **الألعاب التعليمية → رفع لعبة HTML** اختر ملف اللعبة. تحفظ المنصة الملف على الخادم وتعرضه للطالب داخل `iframe` بدون إعطاءه مسار تنزيل.

عند نهاية اللعبة، يجب أن ترسل اللعبة للمنصة:

```js
window.parent.postMessage({
  type: 'EDU_GAME_RESULT',
  score: 8,
  total: 10
}, '*');
```

## واتساب

بدون إعداد خارجي، المنصة تجهز رابط `wa.me` برسالة النتيجة.

للإرسال الآلي من الخادم، اضبط متغيرات البيئة:

```bash
WHATSAPP_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
```

بعدها سيرسل الخادم رسالة نصية لرقم ولي الأمر عند تسجيل النتيجة، مع الاحتفاظ برابط يدوي كخطة بديلة عند فشل API.

## قاعدة البيانات

البيانات تحفظ داخل:

`data/db.json`

والألعاب داخل:

`games/`

هذه النسخة مناسبة للبدء محليًا أو نشرها على خادم Node.js. للحملات الكبيرة يفضل نقل البيانات إلى PostgreSQL/MySQL وتخزين الألعاب على object storage.

## النشر على GitHub + Render

المشروع عبارة عن تطبيق Node.js كامل ويمكن رفع مجلد المشروع إلى GitHub مباشرة. في Render استخدم أمر البناء `npm install` وأمر التشغيل `npm start`، ونقطة فحص الصحة `/api/health`.

للحفاظ على `data/db.json` وملفات الألعاب بعد إعادة التشغيل أو إعادة النشر، اربط القرص الدائم في Render بمجلد، ثم عيّن `DATA_DIR` و`GAMES_DIR` إلى مسارات هذا القرص. بدون تخزين دائم قد تفقد البيانات المحلية وملفات الألعاب عند إعادة إنشاء الخدمة.

لإرسال واتساب تلقائياً من الخادم، أضف `WHATSAPP_TOKEN` و`WHATSAPP_PHONE_NUMBER_ID`، ويمكن ضبط `WHATSAPP_API_VERSION` عند الحاجة.

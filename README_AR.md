# منصّة الدروس — النسخة الجاهزة

منصة تعليمية بخادم Node.js لتسجيل الطلاب، الألعاب التعليمية، الفيديوهات، النتائج، ونشاط الطالب بشكل مركزي.

## التشغيل المحلي

1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد `edu-platform-full`.
3. شغّل:

```bash
node server.js
```

4. افتح:

`http://localhost:3000`

## دخول المعلم

بيانات الدخول الافتراضية للمعلم:

- اسم المستخدم: `redaawad`
- كلمة المرور: `135790`

لا تظهر هذه البيانات على شاشة الدخول. يمكن تغيير كلمة المرور من: **الإعدادات → تغيير كلمة مرور المعلم**.

يمكن تخصيص بيانات الدخول عند التشغيل عبر:

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `PORT`
- `DATA_DIR`
- `GAMES_DIR`

## حساب الطالب وولي الأمر

من **الطلاب → طالب جديد** يتم إنشاء:

- اسم دخول الطالب وكلمة مروره.
- كود دخول ولي الأمر وكلمة مروره.
- رقم هاتف ولي الأمر.
- الصف والصلاحيات.

## الألعاب التعليمية

من **الألعاب التعليمية → رفع لعبة HTML** ارفع ملف اللعبة. تحفظ اللعبة على الخادم وتفتح للطالب داخل المنصة في `iframe` بدون إعطاءه زر تنزيل.

عند انتهاء اللعبة يجب أن ترسل النتيجة:

```js
window.parent.postMessage({
  type: 'EDU_GAME_RESULT',
  score: 8,
  total: 10
}, '*');
```

## متابعة الفيديوهات

يمكن للطالب فتح الفيديو من داخل حسابه باستخدام مشغل HTML5. للحصول على تتبع دقيق استخدم رابط فيديو مباشر مثل MP4 أو WebM.

المنصة تسجل مركزيًا:

- دخول الطالب وخروجه.
- فتح الفيديو وتشغيله وإيقافه.
- التقدم والانتقال داخل الفيديو.
- مدة الفيديو.
- مدة المشاهدة الفعلية المتراكمة.
- أعلى موضع وصل إليه الطالب.
- نسبة المشاهدة.
- عدد مرات فتح الفيديو.
- إكمال الفيديو.
- فتح الألعاب التعليمية.
- نتائج الألعاب.
- زيارات صفحات الطالب.

تظهر هذه البيانات في **متابعة النشاط** أمام المعلم، وفي حساب ولي الأمر داخل قسم **كل ما قام به الطالب**، بالإضافة إلى ملخص مشاهدة لكل فيديو.

> روابط YouTube أو منصات الفيديو الخارجية يمكن تسجيل فتحها، لكن حساب مدة التشغيل الدقيقة يتطلب تكاملًا مع واجهة المنصة الخارجية. التتبع الدقيق هنا مصمم للفيديوهات المباشرة التي يستطيع عنصر HTML5 تشغيلها.

## الدرجات وواتساب

عند تسجيل نتيجة اللعبة تحفظ النتيجة باسم الطالب وتظهر في الدرجات. يمكن تجهيز رسالة عبر `wa.me`، أو إرسالها تلقائيًا من الخادم عند إعداد:

```bash
WHATSAPP_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
WHATSAPP_API_VERSION=v23.0
```

## التخزين

بيانات المنصة تحفظ داخل:

`data/db.json`

والألعاب داخل:

`games/`

يوجد أيضًا سجل النشاط داخل قاعدة بيانات المنصة، مع تحديثات تقدم الفيديوهات لكل طالب.

## GitHub + Render

المشروع جاهز للرفع إلى GitHub ثم نشره على Render كتطبيق Node.js.

`render.yaml` يستخدم قرصًا دائمًا على Render بمسار `/var/data`، ويعين:

- `DATA_DIR=/var/data`
- `GAMES_DIR=/var/data/games`

ويفضل الاحتفاظ بقرص Render الدائم لحماية قاعدة البيانات وملفات الألعاب من فقدانها عند إعادة إنشاء الخدمة.

### النشر

- Build Command: `npm install`
- Start Command: `npm start`
- Health Check: `/api/health`

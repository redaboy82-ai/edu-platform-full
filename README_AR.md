# منصّة الدروس — النسخة الجاهزة

هذه نسخة كاملة تعمل بخادم Node.js بدون مكتبات خارجية.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد `edu-platform-full`.
3. شغّل:

```bash
node server.js
```

4. افتح:

`http://localhost:3000`

## حساب المعلم الافتراضي

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

غيّر كلمة المرور قبل النشر العام. ويمكن تحديد بيانات مختلفة عند أول إنشاء للبيانات عبر متغيرات البيئة:

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `PORT`

## حساب الطالب

من حساب المعلم اختر **الطلاب → طالب جديد**. المنصة تنشئ تلقائيًا:

- اسم دخول الطالب
- كلمة مرور الطالب
- كود ولي الأمر
- كلمة مرور ولي الأمر

يمكن إعطاء الطالب بيانات حسابه وولي الأمر بيانات حساب ولي الأمر.

## الألعاب التعليمية

من **الألعاب التعليمية → رفع لعبة HTML** اختر ملف اللعبة. تحفظ المنصة الملف على الخادم وتعرضه للطالب داخل `iframe` بدون إعطاءه مسار تنزيل.

عند نهاية اللعبة، يجب أن ترسل اللعبة للمنصة:

```js
window.parent.postMessage({
  type: 'EDU_GAME_RESULT',
  score: 8,
  total: 10
}, '*');
```

## واتساب

بدون إعداد خارجي، المنصة تجهز رابط `wa.me` برسالة النتيجة.

للإرسال الآلي من الخادم، اضبط متغيرات البيئة:

```bash
WHATSAPP_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
```

بعدها سيرسل الخادم رسالة نصية لرقم ولي الأمر عند تسجيل النتيجة، مع الاحتفاظ برابط يدوي كخطة بديلة عند فشل API.

## قاعدة البيانات

البيانات تحفظ داخل:

`data/db.json`

والألعاب داخل:

`games/`

هذه النسخة مناسبة للبدء محليًا أو نشرها على خادم Node.js. للحملات الكبيرة يفضل نقل البيانات إلى PostgreSQL/MySQL وتخزين الألعاب على object storage.

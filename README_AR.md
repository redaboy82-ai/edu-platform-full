# تحديثات إدارة المحتوى

تمت إضافة نظام إدارة محتوى موسع مع الحفاظ على وظائف المنصة السابقة:

- التحكم في إتاحة الفيديو والصوت والألعاب والاختبارات والكتب/المذكرات لكل الطلاب أو لطلاب محددين.
- كارت مستقل للكتب والمذكرات في لوحة المعلم.
- رفع PDF والصور (PNG/JPG/WEBP) بنفس أسلوب الرفع الحالي مع شريط تقدم وإغلاق نافذة الحفظ فور بدء الرفع.
- تعديل بيانات الملفات، استبدال الملف نفسه، أو حذفه.
- عرض الملفات للطالب وولي الأمر وفق الصف وقاعدة الإتاحة المحددة من المعلم.
- التحقق من الصلاحيات على الخادم، وليس الواجهة فقط.
- استمرار حساب ولي الأمر الواحد المرتبط بعدة أبناء.

## تشغيل

```bash
npm install
npm start
```

للنشر على Render، يجب استخدام تخزين دائم (Persistent Disk أو خدمة تخزين ملفات خارجية) للمجلدات `data`, `videos`, `audios`, `games`, و`documents` حتى لا تضيع الملفات عند إعادة نشر الخدمة.
